# 商品相册（GitHub 版）

一个只有一个网页文件的相册，放在 GitHub Pages 上就能用。分类最多两层（大分类 → 子分类），每个分类就是一个文件夹，图片就是文件夹里的文件：

```
photos/
  女装/
    连衣裙/
      20261109-213207-01-正面.jpg
    T恤/
      ...
    （大分类里也可以直接放图片）
  运动鞋/
    ...
```

## 一、建立仓库并开启网页（只需做一次）

1. 登录 GitHub，新建一个仓库，名字随意，比如 `album`。
   - 选 **Public（公开）**。免费账号只有公开仓库能用 GitHub Pages，所以图片别人拿到链接是能看到的。
   - 勾选 **Add a README file**。仓库不能是空的。
2. 进入仓库，点 **Add file → Upload files**，上传 `index.html`，然后点 Commit。
3. 打开 **Settings → Pages**：Source 选 *Deploy from a branch*，Branch 选 `main`，文件夹选 `/ (root)`，点 Save。
4. 等 1～2 分钟后打开 `https://你的用户名.github.io/album/`，就能看到相册了。

## 二、开启上传功能（每台要上传的设备做一次）

只看图片不需要登录。要在网页上新建、上传、移动或删除图片，需要先生成一个 Token：

1. GitHub 右上角头像 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**。
2. **Repository access** 选 *Only select repositories*，只勾这个相册仓库。
3. **Permissions → Repository permissions → Contents** 选 **Read and write**。
4. 生成后复制 Token（以 `github_pat_` 开头）。
5. 打开相册网页，点右上角 **⚙ 设置**，把 Token 粘贴进去，然后保存。

Token 只保存在当前这台设备的浏览器里，不会上传到仓库。不要在别人的设备上填写。

## 三、使用说明

- **新建分类**：首页点「新建分类」建大分类；进入大分类后点「＋ 新建子分类」。
- **上传图片**：进入分类后，可以选择图片（支持多选）、拖进来或直接粘贴。默认会把大图压缩到最长边 2400 像素，想保留原图可以在设置里关掉压缩。
- **移动 / 删除**：点一张图放大后可以操作，也可以点「选择」批量操作。
- **重命名 / 删除分类**：在分类页右上角点「⋯」。大分类改名或删除时，下面的子分类会一起改或一起删。
- **分享某个商品**：进入分类后点「分享」，复制链接（格式是 `…/album/?p=商品名`）发给对方。对方只能看这个商品的图片，没有返回首页，也没有任何编辑按钮。商品改名后，旧链接会失效。
- **只读保护**：页面里已经去掉了下载入口，并且禁用了右键、长按保存图片、拖拽图片和 Ctrl+S。
- 刚上传的图片大约 1 分钟后其他设备才能看到，因为 GitHub Pages 需要重新部署。
- 也可以不用这个网页，直接在 GitHub 上进入 `photos` 文件夹上传图片。放在 `photos/分类名/` 或 `photos/分类名/子分类名/` 里就会自动显示。

## 注意事项

- 仓库建议控制在 1GB 以内，单个文件不能超过 100MB。开启压缩可以省很多空间。
- 删除的图片在 Git 历史中仍然可以找回。
- 「不能下载」只能挡住普通用户。截图是挡不住的。另外仓库是公开的，懂技术的人可以从 GitHub 仓库或浏览器开发者工具里拿到原图。如果很在意，可以在上传前给图片加上水印。
- 在国内访问 `github.io` 有时候会比较慢或打不开。
